# Related Extensions and Name Check

Checked September 20, 2026. This is a discovery check, not a reservation or proof that a name cannot later be registered.

- [R Reindent Lines / R Indent (`bescoto.r-reindent`)](https://marketplace.visualstudio.com/items?itemName=bescoto.r-reindent) is a close alternative. Its listing describes explicit selection/current-line reindentation, vertical argument alignment, pipes, and R/Quarto/R Markdown support. RStudio Indent instead focuses on Enter and closing characters while typing R. There is substantial overlap in purpose; this project should not claim uniqueness.
- [Air](https://posit-dev.github.io/air/) provides R formatting and editor support. A whole-document formatter has a different contract from preserving the manual script's indentation choices while typing.
- [VS Code R](https://github.com/REditorSupport/vscode-R) provides broader R language/editor integration. Compatibility with it should be tested, not assumed from using the same language ID.

Exact-name web searches for `rstudio-indent` did not identify an existing extension. Open VSX search results included other R and indentation tools but no exact-name match. Recheck both registries during publisher setup. The proposed ID is `ColinConwell.rstudio-indent`; publisher ownership and registry acceptance still need to be established by the developer.

The name describes an emulated editor behavior. Listing text explicitly identifies Colin Conwell as the independent developer and does not suggest Posit endorsement.
